相反数

考纲关联示意
什么是相反数？
a + (−a) = 0

只有符号不同的两个数互为相反数。它们在数轴上位于原点两侧，到原点的距离相等；0的相反数仍然是0。

不要把相反数和倒数混淆
−a   ≠   1/a

相反数改变的是加法意义下的符号；倒数则与乘积为1有关。对于非零的a，两者通常不同；0没有倒数。

从有理数推广到实数范围
x + (−x) = 0

相反数的关系同样适用于实数。无论x是有理数还是无理数，−x都是它的相反数。
